# Oink 사용자용 웹앱 (`webapp/`, PWA)

처리기를 쓰는 사람용 화면: 미생물 친구 Oink 캐릭터, 쉬운 말 상태 요약, 음식물 투입 기록, 분해 진행 추정, 안전한 히터 조절. 팀용 센서값 화면은 `cloud-dashboard/`.
서버 없음 — 브라우저가 wss로 EMQX에 직접 접속(`wss://o9f10aca.ala.asia-southeast1.emqxsl.com:8084/mqtt`, 계정 `oink-web`). 토픽 규격은 `firmware/MQTT_PROTOCOL.md`.

## 배포·설치 (HTTPS 필요)
- GitHub Pages(현재 배포): 공개 저장소 `mgalkseo04d4-lab/oink-web`의 `app/`에 이 폴더를 복사해 푸시 → https://mgalkseo04d4-lab.github.io/oink-web/app/ (HTTPS라 PWA 설치 가능). Netlify는 11/03 크레딧 소진으로 중단.
- 안드로이드 Chrome: 주소 열기 → 메뉴(⋮) → "앱 설치" 또는 "홈 화면에 추가".
- 아이폰 Safari: 주소 열기 → 공유 → "홈 화면에 추가".
- 앱을 고치면 `sw.js`의 `CACHE` 이름(현재 oink-shell-v4)을 올려야 설치된 폰에 새 버전이 반영된다.

## 화면 동작
- 캐릭터: 데이터 없음/게이트웨이 꺼짐 = 자는 중, 냄새 지수 ≥ 2 = 냄새(상단 경보), CO₂ 5분 기울기 > 0 = 분해 중, 그 외 = 편안. 판정은 `logic.mjs`, 확인은 `node webapp/selfcheck.mjs`.
- 음식물 기록: `oink/app/feed_log`에 최근 20건 배열을 retained로 저장(서버 없이 기기 간 공유). 거의 동시에 두 기기가 기록하면 하나가 덮일 수 있음.
- 분해 진행: 마지막 투입 후 max(경과/48시간, CO₂ 피크 대비 하강률). 앱을 연 동안 쌓인 CO₂만 쓰는 추정치.
- 히터: "강제로 끄기"(두 번 눌러야 실행), "자동으로 돌리기" 토글, 목표 온도 30~40℃. `oink/gateway/cmd`로 보내고 5초 안에 `oink/gateway/cmd/ack`가 오면 "적용함". **강제 ON은 없다**(안전 판단은 보드#2 로컬). 게이트웨이 펌웨어가 cmd를 아직 처리하지 않으면 "기기 응답 없음"이 정상.
- 오프라인: 앱 셸은 캐시돼 열리지만 "인터넷 연결이 필요해요" 표시, 로그인 막힘.

## 테스트 (공개 브로커)
`app.js`의 `BROKER`를 `wss://broker.emqx.io:8084/mqtt`로 바꿔서 로컬에서 열고, 아이디·비밀번호 비움(커밋 금지). 공개라 누구나 같은 토픽을 볼 수 있으니 테스트 전용. 평소엔 주소 고정이라 로그인 화면엔 아이디(기본 `oink-web`)·비밀번호만 있다.
- 기본 계정 oink-web/oink-web이 채워져 있음 — 공개 사이트라 누구나 접속 가능, 비공개가 필요하면 EMQX에서 비번 변경 후 기본값 제거.
- 로그인 유지는 기기에 비번을 저장함 — 공용 기기에서는 체크 해제. 로그아웃하면 저장된 정보가 지워진다.
- 출처 배지: 2보드(firmware2, 가짜값 모드 없음)는 자동으로 "실측". 구 3보드 펌웨어면 `app.js`의 `FAKE_B1`에 따라 "시험값".
